# gpt-diet-fitness
Building a diet and fitness tracker that works for my brain around OpenAI APIs. This is a personal side project, so the format of the fitness and nutrition tracking is somewhat specific to how I see things, but I think the general state management pattern is flexible enough to be useful in other contexts. Or maybe not who knows! Also somebody let me know if this is already a thing. 

**The very high level idea:**

 - Store general information about the user as state objects
 - Store highly detailed information about the user's activity and diet history
 - Also store generated summaries and tables to show in the UI / dashboard
 - Send and update the appropriate state objects depending on the prompt the user is submitting. _For example_, a photo of a meal with a description of what it is, would:
   - Include general information about the user's diet and goals 
   - Include the appropriate state objects (what the user had already eaten, their recent physical activity)
   - Include instructions for how to handle that type of request, like how to update provided state objects
   - Trigger an event that the on response that updates the state objects (including summaries) with the updated nutritional information

**The somewhat high level idea:**
 - Detailed information about the user's goals, general activity level, dietary restrictions, and eating habits. Some of this information is generated via onboarding prompts. This information is sent with *every* query.
 - What the user has eaten that day, as well as detailed nutritional information.
